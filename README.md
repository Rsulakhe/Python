# Python and Django Learning Journey

I'm a frontend developer (React, React Native, TypeScript) with about 6 years of experience, learning Python and Django to grow into a full-stack role. This repo holds my practice code, projects, and a daily log of what I learn.

## Goal

Learn Python and Django in 30 days (about 4 hours a day), finishing with a deployed full-stack project: React frontend, Django REST backend, JWT auth, and an AI-powered feature.

- [ ] Serializers, viewsets, routers

- [ ] **Capstone:** AI-powered study platform (React + Django REST + LLM API)
